# Решения задач из учебника В. А. Зорича «Математический анализ. Часть I»

Мои собственные решения задач из книги:

> Зорич В. А. Математический анализ. Часть I. — Изд. 10-е, испр. — М.: МЦНМО.

Решения не являются официальными и могут содержать ошибки. Номера страниц в файлах указаны по этому изданию.

## Как читать

- Оглавление и прогресс — в [Zorich-part1/README.md](Zorich-part1/README.md).
- Одна задача — один файл: `chNN-<глава>/sN-<параграф>/NN.md`.
- В каждом файле разделы «Условие», «Решение», «Заметки».
- Статусы: ⬜ не решена · 🟨 в процессе · ✅ решена.
- Формулы записаны в LaTeX и отображаются на GitHub и в предпросмотре Markdown в VS Code.
